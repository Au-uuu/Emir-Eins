# 字体来源

`NotoSansSC-Bold.ttf` 来自 Noto Sans SC（Google / Adobe），
使用 SIL Open Font License 1.1。

- 项目：<https://github.com/notofonts/noto-cjk>
- 许可：<https://openfontlicense.org/open-font-license-official-text/>

文件取自 `MemeCrafters/meme-generator` 的 `resources/fonts/NotoSansSC-Bold.ttf`，
用于在没有中文字体的服务器上渲染 `/搓图` 文本。
