# 2026-09-21 关键词关联（别名）

## 需求

- 支持把多个关键词关联到同一个「主关键词」：`/来只 A` 和 `/来只 B` 最终都等价于 `/来只 A`。
- 支持**取消关联**与**查找关联**。
- 关联集合只有一个主关键词；所有别名**只连接主关键词**；断连也只与主关键词断连。
- 关联集合是**单层星型**结构，不允许别名串联别名。

## 设计

### 数据模型

新增表 `keyword_links`：

| 列 | 说明 |
|---|---|
| `alias` | 别名关键词（主键） |
| `main` | 所属主关键词 |
| `added_at` | 建立时间 |

不变式：

1. `alias != main`。
2. 主关键词自己绝不会作为 `alias` 出现（`resolve` 保证最终指向非别名）。
3. 任何别名都直连主关键词，不存在「别名 → 别名 → 主」的二级链。

### 行为

- **解析**：`resolve_keyword(kw)` 沿 `alias → main` 走，最多 8 跳（仅作历史脏数据兜底）。
- **写透明**：`/添加` 入库前把每个关键词解析到主关键词，别名不落库，图片只沉淀在主关键词上。
- **读透明**：`/来只`、`/图库`、按关键词取图/搜索都先解析别名。
- **建立关联** `/关联 主 别名…`：
  - 主若本身是别名，先解析到根主，避免二级串联。
  - 别名若原本是别的主，把它的别名一并改挂到根主（保持单层）。
  - 把库里已经用别名标注的图片改标到主关键词（合并存量），保证别名与主真正等价。
- **取消关联** `/取消关联 关键词`：只把该关键词移出集合。
  - 传别名：删「别名 → 主」这一条边。
  - 传主关键词：**当时实现为解散整个集合**，后续已改为自动改选新主、集合保持完整，见
    [2026-09-21-unlink-reassign-main](2026-09-21-unlink-reassign-main.md)。
- **查找关联** `/查找关联 [词]`：给词则显示它所在集合；不带参数则列出所有集合。

### 指令

| 指令 | 说明 |
|---|---|
| `/关联 主关键词 别名1 别名2 …` | 建立关联（斜杠可省略） |
| `/取消关联 别名 …` | 断开别名；传主关键词则解散集合 |
| `/查找关联 [关键词]` | 查看关联 |
