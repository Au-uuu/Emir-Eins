# 2026-09-21 取消关联改为「只移出单个词，集合不受影响」

## 背景

上一版 [keyword-links](2026-09-21-keyword-links.md) 里，`/取消关联 <主关键词>` 会**解散整个集合**，
其别名全部断开。实际需求是：

> 主关键词是谁无所谓。取消关联只取消「这个词」和集合的关联，不影响集合本身。

## 新行为

`/取消关联 <关键词>` 无论传的是别名还是主关键词，都只把**这一个词**移出集合：

- **移出别名**：删除「别名 → 主」这一条边。集合其余成员不变。
- **移出主关键词**：
  1. 从剩余成员里自动选一个新主（取字典序最小者，结果稳定可复现）；
  2. 新主不再作为别名存在；
  3. 其余成员全部改挂新主；
  4. **图片池随集合迁移到新主**（把旧主名下的 `keywords` 行合并到新主），
     旧主退化成普通关键词，不再享有集合的图片；
  5. 集合本身保持完整，其余成员关联不受影响。
- **既非别名也非主**：返回 `missing`，提示无关联。

> 「图片池迁移」的含义：集合的图片归属于**集合**而非某个具体词。主关键词只是集合当前的
> 代表名，换主时图片跟着集合走，保证 `/来只 新主` 仍能取到原来那批图。

## 改动文件

- `image_store.py`
  - `UnlinkResult` 文档更新：`kind=main` 现在表示「主词被移出并已改选新主」，
    `main` 为新主，`count` 为剩余成员数。
  - `_unlink_sync` 重写主关键词分支：改选新主 + 改挂剩余成员 + 迁移图片池，不再删除整个集合。
- `bot.py`
  - `do_unlink` 输出文案更新；`Usage` 文案更新。
- `_test_links.py`
  - `[5]` 增补：用别名入库沉淀到主词的图片池。
  - `[7]` 重写：别名移出、主词移出后自动改选新主、集合保留、图片池迁移、旧主退化。
  - `[8]` 增补：指令层「移出主词」提示文案与新主断言。
- `README.md`：关联说明与指令表同步。

## 备注

- 新主选择规则是「字典序最小」，目的是结果确定、可测试。若日后想改成「图片最多的词当主」
  或「最早加入的词当主」，只需改 `_unlink_sync` 里 `new_main` 的取法。
- 集合只剩一个成员时，移出主词后集合自然退化为单个普通关键词（没有关联边），
  这属于预期：已经没有别的词可关联了。
