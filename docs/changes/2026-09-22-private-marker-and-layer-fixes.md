# 2026-09-22 私有标识改括号 + 分层相关 bug 修复

## 私有标识

`/图库` 列表用括号区分层级，不再写 `[私有]`：

- 公开层：`名称(数量)`
- 本群私有层：`名称[数量]`

例：`猫(12)-猫咪 / 狗[3]`

## 修复的 bug（分层重构遗留）

1. **改主词丢层**：`_unlink_sync` 主词移出、改选新主时，图片迁移语句漏了
   `owner_group`，会把私有层压成公开层。已改为保留各自层。
2. **改主词丢私有标记**：`_unlink_sync` 改选新主后，`gallery_privacy` 里的标记
   仍挂在旧主上，导致新主在群里 `/添加` 不会进私有层。已迁移标记到新主。
3. **关联别名丢私有标记**：`_link_sync` 把别名并入主词时，未迁移别名的私有标记，
   导致别名私有失效。已迁移。
4. **删除图库残留标记**：`_delete_gallery_with`（管理员删独立图库）未清理
   `gallery_privacy`，残留标记会让以后 `/添加` 同名关键词意外进私有层。已清理。
5. **空图库残留标记**：`_purge_empty_collections_with` 现在会顺带清理
   「没有任何图片」的私有标记，避免图库消失后标记悬空。

- `bot.py`：`build_gallery_list_text` 层级标识改括号；docstring 更新。
