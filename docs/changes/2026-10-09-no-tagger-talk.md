# 角色卡：回复中不得提及「打标器/识别线索」，非动漫图无视线索

日期：2026-10-09

## 现象

用户发了一张**纯文字软件截图**，机器人回复里出现
「与识别线索中雾雨魔理沙舰队Collection完全不符」「离线打标器误判」等**内部工具术语**。

## 原因

- 图片**无条件过离线打标器（Camie）**：截图等域外图被强行套上弱命中标签
  （雾雨魔理沙、舰队Collection），进入「识别线索」。
- 角色卡此前只规定「矛盾时以画面为准」，没禁止**把打标器/线索这些内部概念说出口**。

## 需求与改动

用户要求：**打标照跑（不改代码），但回复里不能带打标器判断；与动漫无关时不提**。

`persona/依蜜尔爱因.md`：

- §0 新增：
  「输入里的「识别线索/角色候选」是本机**内部工具**的原始输出，**回复中绝不提及**
  （不许出现「打标器/离线打标器/识别线索/标签/候选」这类字眼），也不评价线索对错；
  **画面不是动漫/游戏内容时（截图、界面、照片、表情包、风景、食物等）直接无视线索**，
  只按画面本身回应。」
- §8「善用识别线索」改为**仅限画面为动漫/游戏角色时**使用，并重申任何情况下都不得在
  回复里出现上述字眼。
