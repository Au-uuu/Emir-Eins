# 角色卡重写：看图识别 + 群聊守则

日期：2026-10-07

## 需求

用户反馈两个问题：

1. **发图被说成「本机的自拍」**：机器人动辄回复「本机的自拍……能成为主人的配菜……吗？」。
2. 群聊里复读、回复样式不适合群场景。

排查确认根因在角色卡：

- 那句台词**原样写在 §3 示例表**（「示弱」行的例句），且是全卡唯一与图片沾边的
  句子——只发图不说话时，模型在卡里找不到「如何回应图片」的指引，就往最接近的
  示例上靠，原句背出。
- **记忆回路强化**：回复写入 20 分钟会话记忆，下一张图看到自己上次的回复，继续照抄
  （日志实锤：同一时段「【恍惚】……嗯～（脸红）」连回 3 次）。
- 卡里完全没有群聊行为约束：回复长度、恋爱脑边界、复读防护都是空白。

## 设计（对照 MaiBot 等开源群聊 bot 的经验：短句口语、严防复读、被叫才说话）

改动全部在 `persona/依蜜尔爱因.md`，人设内核（§1~§7、标签系统、毒舌+恋爱脑）不动：

| 位置 | 改动 |
|---|---|
| §0 演出要求 | 单聊/群聊回复长度分开（群聊 1~2 句封顶）；「示例禁止逐字照搬」从 §9 标题升级为最高优先级硬规则，覆盖 §3 表格 |
| §3 示例表 | **删掉「本机的自拍……配菜……吗？」例句**，换成不涉及图片的示弱例句；表头加「例句仅示范格式，禁止照搬」 |
| §4 性格 | 恋爱大脑标注「只对主人生效」 |
| **§8 看图行为（新增）** | 先看后说：第一句【分析】/【报告】客观说出图里有什么，再入戏点评；照实识别，认不出就【疑问】不编造；**「图是对方发的，不是本机发的」——动漫图/头像/截图都不是本机的自拍**；动图三帧推定动作；不同图不复读同一句 |
| **§9 群聊守则（新增）** | 群里默认全是未知个体（单聊才默认主人）；只在被 @ 时开口、只回应相关的那句；回复 1~2 句；恋爱脑对未知个体关闭（被调戏→警告+害羞当机/毒舌）；防复读三连：不重复自己、不跟风、同梗只嘲一次 |
| §10/§11 | 原「边界」「对话示例」顺延编号，§0 的引用同步更新；§11 新增两条看图示例（橘猫咬数据线、二次元立绘）锚定「先描述后吐槽」 |

原 §8 例句引用的 §3 表格行号无变化；§0 中「按 §8 处理」改为「按 §10 处理」。

## 测试报告

### 自动化 + 真实冒烟（本机，2026-10-07）

- 全套件 **16/16 通过**（角色卡不参与代码测试，但确认加载正常：4647 字，旧卡 3485 字）
- **真实 API 冒烟 1（看图）**：程序画了一张「深蓝夜空+黄色圆月+三颗星」发给视觉模型
  （新卡 + 「（发了一张图片）」占位）→ 回复：
  【报告】图像主体为深蓝色夜空背景，右侧有一轮明亮的黄色圆形月亮，左上方分布三颗
  白色小星点。无其他可见物体或文字。【恍惚】……这月色真美～（脸红）
  → **先客观识图再入戏，无「自拍」无「配菜」** ✅
- **真实 API 冒烟 2（群聊调戏）**：「妹妹你好可爱，可以做我女朋友吗」→
  【拒绝】请报告个体名。本机不会接受来自未知个体的不当发言。【警告】请尊重本机与
  主人的关系。→ **45 字短回复、毒舌、不恋爱脑** ✅

### 待人工（部署后）

1. 群里发一张动漫图（不说话）→ 应报出画面内容（风格/角色特征），不再说「本机的自拍」
2. 群里 @ 它闲聊几句 → 回复应在 1~2 句内，不复读
3. 群里有人调戏 → 应被警告/毒舌挡回，不发嗲
4. 单聊发图+问「这是什么」→ 识图正常（此前已验证过夜鹭幼鸟案例）
5. ⚠️ 部署后 20 分钟内若仍偶发复读，是旧会话记忆的尾巴（TTL 20 分钟），之后自愈；
   彻底立竿见影需要「/清空」指令（chat_store.clear() 已实现未接线，待排期）

## 已知限制

- 群聊里管理员（真人主人金鑫）也会被当「未知个体」对待——识别主人身份需要
  openid 绑定，属代码层功能，卡里写不了；如需要后续加「主人白名单」。
- 视觉模型的语气贴合度仍弱于 qwen-flash-character（模型本身非角色特调），
  卡片强化后已有「先分析后入戏」的兜底结构。
