# 群友随机接话

- 日期：2026-10-27
- 涉及：`bot.py`、`_test_random_reply.py`（新）、`.env.example`、`README.md`、
  `docs/ENV-AND-PITFALLS.md`

## 需求

群「全量模式」下，群友没 @ 机器人时，机器人可以**按概率**偶尔接一句。
默认概率 0（完全关闭），由 `.env` 设置。

## 行为

只在 `on_group_message_create`（全量模式）里生效。一条消息要同时满足：

1. 不是指令（`handle_command` 没处理）；
2. 没 @ 机器人（`mentions_me` 为假）；
3. 没命中 `QQ_BOT_KEYWORD`（命中就走原来的关键词回复）；
4. 内容非空、不以 `/` 开头；
5. `persona.available()` 为真（配了文本 Key + 角色卡）；
6. `random.random() < QQ_BOT_RANDOM_REPLY`；
7. 该群不在随机接话冷却期内。

回复直接走 `persona_reply`，所以会经过人格、群聊上下文、延迟、拆条、敏感词过滤；
发送用当前消息的 `msg_id`，属于**被动回复**，不占每月 4 条主动消息额度。

## 配置

```ini
# 默认 0 = 完全不接；建议 0.02~0.05（2%~5%）
QQ_BOT_RANDOM_REPLY=0
# 同一群两次随机接话的最小间隔（秒），默认 300
QQ_BOT_RANDOM_REPLY_COOLDOWN=300
```

概率支持三种写法：`0.03`、`3%`、`3`，内部统一到 0~1。

## 实现细节

- `_env_prob()`：解析概率，非法值回退默认 0；
- `should_random_reply()`：过滤 + 概率 + 每群 `Cooldown`；
- 冷却只在**概率命中后**才占用，不会因为一次没掷中就提前锁住；
- 处理器里先走关键词分支（保持原行为），命中关键词就 `return`，
  没有关键词/没命中才进入随机接话；
- 启动日志会打印：
  - 关：`群友随机接话：关（QQ_BOT_RANDOM_REPLY=0）`
  - 开：`群友随机接话：开（概率 3.0%，每群冷却 300 秒）`

## 测试

新增 `_test_random_reply.py`：

- 100% 时普通消息通过，空消息/斜杠指令不接；
- 概率 0 时永远不接；
- 同群冷却期内拒绝、换群不受影响；
- 处理器接线：没 @、没关键词时调用 `persona_reply`；
  概率 0 时不调用。

## 建议

- 先设 `0.02`（2%）跑一天，观察群友反应；
- 群很活跃可以降到 `0.01`，冷清群可以到 `0.05`；
- 如果觉得它插话太频繁，先调大 `QQ_BOT_RANDOM_REPLY_COOLDOWN`，再降概率；
- 不要设到 `0.2` 以上，容易变成刷屏机器人。

## 回滚

`QQ_BOT_RANDOM_REPLY=0` 后重启即可完全关闭，不影响其他功能。
