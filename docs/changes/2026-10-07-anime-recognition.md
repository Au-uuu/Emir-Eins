# 动漫角色识别：卡片指引 + 视觉模型升级 qwen3-vl-plus

日期：2026-10-07

## 需求

用户希望机器人能认出一些动漫人物，而不是把所有二次元图都说成「本机的自拍」。

## 做法

### 1. 角色卡 §8 补「动漫角色尽力报名」

- 图里是动漫/游戏角色时尽量报出作品名与角色名，格式如
  【分析】检测到疑似《作品名》的角色○○……
- 作品名比角色名好认，能认到哪一级说到哪一级；**没把握就只描述外形特征
  （发色/瞳色/服饰/道具）并【疑问】请对方告知——认错人比不认更失礼，绝不编造**。

### 2. 视觉模型选型：flash → plus（生产 .env 显式配置）

用服务器图库 7 张带群友关键词的图 + 初音未来 V6 官方立绘，对两个模型做了实测：

| 观察点 | qwen3-vl-flash | qwen3-vl-plus |
|---|---|---|
| 初音未来 | ✅ 认出（版本说成 V4X，实为 V6） | ✅ 认出，且指出「01」臂章、判断为二创变体并追问版本 |
| 不认识的图 | ❌ 瞎猜名字（原神七七/星熊，均错） | ✅ 老实问「出自哪部作品」，不编 |
| 卡片遵从 | ❌ 又出现一次「本机的自拍？」 | ✅ 零自拍发言，连「动图三帧→动作轨迹推定」都照做 |
| 细节读取 | 一般 | 更强（bilibili 水印、订单截图全文、群标文字都能读出） |

**结论：生产 `QQ_BOT_QWEN_VL_MODEL=qwen3-vl-plus`**（.env 显式覆盖，代码默认值仍为
qwen3-vl-flash）。plus 单价高于 flash，但按当前用量（周 ~40K token）月增费用在
几块钱内；换来的是「不编名字、不瞎认自拍」这两个用户可感知的行为修复。

### 3. 测试集说明（重要局限）

服务器图库的关键词多为**群内梗名**（「菲比」实为像素蜜蜂梗图、「蓝色大肥鱼」等），
不是标准角色名——冷门梗图两个模型都认不出属预期，新卡的行为兜底是「描述特征 +
【疑问】求补充」。知名角色（初音级）两个模型都能认，plus 更准。
