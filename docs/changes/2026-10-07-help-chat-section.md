# /help 加入 AI 聊天（闲聊/看图）介绍

日期：2026-10-07

## 需求

人格聊天 + 看图上线后，`/help` 里完全没有这两块的玩法说明——群友不知道机器人
能闲聊、能看图。用户要求把 AI 聊天的介绍加进帮助。

## 设计

- 帮助开头一句带出双重身份：`我是群助手依蜜尔爱因，可以收藏图片、随机取图，
  也能闲聊、看图。`（保留「我是群助手」前缀——`_test_reply_policy` 等 5 处测试
  断言锚定这个子串）
- 新增【闲聊】小节，置于所有图片库指令之前（闲聊是零门槛玩法，放最前面）：
  - 不输指令直接说话就能聊：单聊直接说，群里要 @ 我
  - 看图：单聊直接发图，群里 @ 我发图，能看懂图说话（动图看前中后三帧）
  - 闲聊发的图片只用来回复，不会被收藏进图库（顺带把隐私边界写清楚，和
    隐私协议口径一致）
- 帮助图高度由 `text_image` 按行数自适应（上限 20000px），加 3 行无需改渲染参数。
