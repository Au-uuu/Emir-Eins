# 看图行为重写：回应优先、打标线索弱化（KB 图像识别已回退）

日期：2026-10-10

## 现象

1. 图里明明是梗（文案「和笨蛋对视」「正在观察猪」），机器人却只报「【分析】检测到…发色…
   瞳色…背景…」的**特征清单**，不回应内容。
2. 打标器不认得 2025+ 新作，会把**橘雪莉认成 hololive 的兔田佩克拉**，而此前角色卡要求
   「优先信任打标线索」，于是错得更自信。

## 改动（`persona/依蜜尔爱因.md` §8 / §11、`bot.py::tagger_hints`）

- 「**先看后说**（先客观描述）」→「**看图的主体是「回应」，不是「识别」**」：
  收到图片先对内容**吐槽/接梗/回答**，识别只顺带一句；**禁止**把特征清单当回复主体。
- 「认不出就【疑问】求证」→ 日常发图**不再逢图追问**；只有对方明显在问「这是谁」才求证。
- 打标线索：明确**低置信候选「只是疑似、不是结论」，与画面不符就完全忽略**
  （防「橘雪莉→兔田佩克拉」这类误报；打标器不覆盖 2025+ 新作）。
- §11 清掉两处反面示范（「未知个体，这是哪个作品的角色？」「检测到图像：橘猫个体」）。
- `tagger_hints` 的「疑似候选」措辞同步放弱。

## 中途加了又回退的功能

一度加了「打标器不确定 → 视觉描述 → 知识库检索 → 注入命中角色」的兜底，想把橘雪莉
认出来。**实测误报太高**（蓝发一撞就命中，实际不是橘雪莉），已**整条回退**：
`bot.py` 的 `kb_from_image`/`kb_hits` 注入、`persona.describe` 兜底、角色卡里
「知识库收录的角色以知识库为准」条款全部删除。

> 结论：**图像识别宁可不认，也别认错**。知识库只用于「按文字提问」的检索，不参与认图。
