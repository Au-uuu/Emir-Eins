# 知识库内容：从萌娘百科抓「世界观 + 角色设定」

日期：2026-10-09

## 需求

把「世界观 + 角色设定」从 wiki / 萌娘百科 放进本地知识库（配合 `kb.py` 的 RAG）。
用**便宜的 Qwen 小模型**来整理资料，尽量只用**免费额度**。

## 来源与范围

- **正文来源：萌娘百科**（MediaWiki API 的 `extracts`）。`prts.wiki`（明日方舟 wiki）的
  extract 返回空，不采用。
- **角色名单**：从 `data/tag_zh.sqlite`（Danbooru 中英对照表，`category=4`）按作品后缀
  枚举后去重。
- **覆盖作品**：明日方舟、终末地、原神、赛马娘 Pretty Derby、崩坏：星穹铁道、
  彩虹六号：围攻（R6 只收「围攻」）。

## 方法（`tools/build_kb_server.py`，在服务器上跑）

1. 枚举角色中文名（去掉 `（作品）` 后缀、去重）。
2. 萌百抓正文；**消歧义页**（如「德克萨斯」「博士」）自动改用「名字 + 作品名」搜索，
   定位到该作品的角色页，避免抓到「XX 可以指…」的列表。
3. 正则粗筛：按 `==标题==` 切段，**只保留设定类且非空**的段
   （简介/经历/相关/设定/性格/外貌/能力/故事/剧情/档案/履历/密录），
   丢弃面板/技能/台词/招聘/信物/游戏内表现等。
4. 交给**便宜的 Qwen 模型**（`qwen3.5-flash` → `qwen3.6-flash` → `qwen-flash` →
   `qwen-turbo` → `qwen3.7-flash` 按序轮换）润色成 150~250 字设定条目；
   额度/限流失败自动换下一个模型；整理结果为「无」或过短则**跳过该角色**。
5. 写 `data/kb/<作品>.md`，并缓存 `data/kb_cache/`（重跑不重复烧 token）。

## 免费额度

阿里云百炼新用户**每个模型各 100 万 tokens**免费额度（90 天，中国内地版）。
脚本用便宜模型 + 粗筛缩短输入 + 缓存，尽量压在免费额度内；单模型额度用尽会自动换下一个。

## 与 RAG 的衔接

`kb.py`（纯本地 BM25，见 [local-kb-rag](2026-10-09-local-kb-rag.md)）已就绪；
生成的 `data/kb/*.md` 放在服务器后**重启即生效**（`kb.py` 懒加载一次）。
