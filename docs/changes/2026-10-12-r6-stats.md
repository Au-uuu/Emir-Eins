# R6 战绩查询：`/r6` 指令（R6 Arenyze 公开 API）

日期：2026-10-12

## 需求

群友想查彩虹六号战绩：**按昵称查、去掉封禁状态、要有历史战绩**。
（「当前对局」已确认服务端拿不到——实时数据只存在于游戏客户端本机，不做。）

## 数据源

**R6 Arenyze 的公开 REST API**（正规接口，不是爬虫）：`https://public-api.arenyze.com/r6/api`，
用 `api-key` 头鉴权（key 存 `.env` 的 `QQ_BOT_R6_KEY`；免费额度 2000 次/月，结果 5 分钟缓存）。

- `GET /v2/profile`：账号等级、当前排位面板、逐赛季 segments、RP 历史
- `GET /v2/fullstats`：逐赛季 + 逐干员 + 总时长
- `GET /ranks?version=v7`：RP → 段位名映射

选它的原因：服务器直连（约 1s）、无需育碧账号、不碰 Cloudflare、不吃内存。

## 实现

- `r6stats.py`：查询 + 归一 + 排版；TTL 缓存省额度。
  **只取 `gamemode=pvp_ranked` 且带赛季号的分段**——同一赛季还有事件/休闲/标准等分段
  （某玩家 119 段），不过滤会把「事件模式」当成本赛季（踩过）。
- `bot.py`：新增 `/r6 [平台] 昵称`（平台 pc/ps/xbox，默认 pc），并在帮助文案里加一行。

## 拿不到的（重要）

**「每场对局详情」（地图/比分/单场 K/D）该 API 没有**——探测 `/v2/matches`、`/v2/history` 等
均 404，只有「逐赛季」与「RP 随时间变化」。TN / stats.cc 的逐场列表被 Cloudflare 拦、
且 Tracker Network 明文封禁爬虫。
