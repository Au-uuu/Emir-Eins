# 知识库采集修复与扩面：resolve 修复 / 模型池 / --works / 额度观测

日期：2026-10-10

## 问题

萌百封禁了所有 `list=*` 接口（`list=search` 返回 `action-notallowed: Unauthorized API call`），
`tools/build_kb_server.py::resolve()` 里「消歧义页 → 搜索兜底」这条链路整条失效。
后果：**消歧义多的作品几乎全军覆没**——碧蓝航线 936 个候选只出 22 条（舰名几乎都是消歧义页）。

## 改动（`tools/build_kb_server.py`）

- **`resolve()` 重写**：直接命中（非消歧义）照旧；否则
  1. 先试限定标题「作品:角色」「角色（作品）」「角色(作品)」；
  2. 再读消歧义页的 `prop=links`，按与作品名的相关度挑最合适的一条
     （萌百角色子页面形如「碧蓝航线:大凤」）。
  实测：碧蓝航线样例 0/12 → 19/20；全量轮 **碧蓝航线 22 → 418**。
- **模型轮换表重排**：换成百炼后台额度充足的一批（qwen3.6/3.5 系、qwen3.6-27b/35b、
  deepseek-v4-pro、kimi-k2.5/2.6/2.7、glm-5/5.1/5.2、qwen3.7-max 等，共 20 个，实测均可调通）。
- **`--works`**：只跑指定作品（补跑/重头像更快）。
- **额度观测**：日志打 `[额度] 模型 → quota`，状态变化才打印；轮换表全部耗尽自动停。
- **新增 `tools/kb_appearance.py`**：给条目补「外貌」——优先萌百「外貌/形象」章节原文，
  太省则取萌百立绘让视觉模型客观描述。
- **新增作品**：魔裁（《魔法少女的魔女审判》，Danbooru 无统一后缀 → 走手写名单）、
  蓝色大肥鱼（DeepSeek 鲸鱼娘拟人）。

## 效果（全量补缺轮，13 部）

角色条目 **1149 → 1851（+702，+61%）**：碧蓝航线 +396、明日方舟 +92、蔚蓝档案 +58、
原神 +37、星穹铁道 +28、崩坏3 +16…；本轮仅用约 35 万 tokens。

  该识别因误报过高已**回退**（见 [image-reply-respond-first](2026-10-10-image-reply-respond-first.md)），
  外貌行现在只作为条目的正常内容保留。
- 脚本跑在服务器上，不进代码包；本次已 scp 到 `/tmp/build_kb_server.py`。
