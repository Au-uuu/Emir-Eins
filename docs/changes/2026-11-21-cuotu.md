# 搓图：/搓图 <表情名> <要加的字>

- 日期：2026-11-21
- 模块：`cuotu.py`、`bot.py`、`assets/`
- 影响：新增群聊/单聊指令

## 需求

发两段文字就能出一张“角色说这句话”的表情包，例如：

```text
/搓图 睦子米 今天也不想上班
/搓图 大肥鱼说 正在思考中……
```

第一个空格前是表情名，后面全部算要加的字（文字里可以有空格）。

## 模板来源

使用现成的说话模板，而不是自己画：

### 睦子米

- 上游：<https://github.com/anyliew/meme_emoji>
- 模板：`emoji/mygo_wakaba_mutsumi_say`
- 关键词：`睦子米` / `睦子米说` / `若叶睦说`
- 4 张底图（512/384/500/500），空白气泡位置沿用原模板坐标

### 大肥鱼说（DeepSeek / 鲸鱼娘）

- 原图：梗鲸档案馆 #280
  <https://aigengtu.com/zh/meme/280>
- 原图 1280×1216，气泡里原本是“已思考（用时13秒）> 臭婊子。”
- `assets/memes/deepseek_think/1.png` 是去掉原文字后的空白底图
- 渲染时自动加灰色 `已思考（用时X秒）>`（X 每张随机 3~30），正文在下方左对齐
- 不再使用上游 `deepseek_say` 的 4 张空白气泡图（用户指定要带思考条的版本）

睦子米模板来自 upstream `anyliew/meme_emoji`，MIT；
大肥鱼底图来自梗鲸档案馆，原作者未标注、授权状态不明，仅用于群内非商业表情包。

字体使用 `NotoSansSC-Bold.ttf`（SIL Open Font License），
避免服务器没有中文字体时出方块。

## 实现

### `cuotu.py`

- 模板注册表：`_TEMPLATES["mutsumi"]`、`_TEMPLATES["deepseek"]`
- 别名：
  - 睦子米 / 睦子米说 / 若叶睦 / 睦头人 / 小黄瓜 / 睦 / mutsumi
  - 大肥鱼说 / 大肥鱼 / DeepSeek说 / 鲸鱼娘说 / 鲸鱼娘 / deepseek
- `split_args()` 只按第一个空白拆分，保留文字中的空格
- 文字画进气泡：
  - 从大到小试字号，自动换行
  - 睦子米居中绘制；大肥鱼左对齐，上方单独画灰色思考条
  - 建议 24~40 字；超长会自动缩小字号，缩到最小仍塞不下才拒绝
- 输出 JPEG（quality 90）
- 睦子米随机 4 张底图；大肥鱼固定 1 张（测试可传 `number`）

### `bot.py`

- 新指令：`/搓图`，必须带斜杠
- 子命令：
  - `/搓图` → 完整用法
  - `/搓图 列表` → 当前支持的表情
  - `/搓图 睦子米` → 缺文字提示
  - `/搓图 不存在 文字` → 列出可用表情
- 每个会话每人 3 秒冷却（`QQ_BOT_CUOTU_COOLDOWN`，`0` 关闭）
- 图片走现有 `_reply_image_bytes()`，被动回复，不占主动消息额度
- `/help 搓图` 和主帮助均已接线

### 素材

```text
assets/
├─ fonts/NotoSansSC-Bold.ttf
└─ memes/
   ├─ mygo_wakaba_mutsumi_say/
   │  ├─ 1.png  (512×512)
   │  ├─ 2.png  (384×384)
   │  ├─ 3.png  (500×500)
   │  └─ 4.png  (500×500)
   └─ deepseek_think/
      └─ 1.png  (1280×1216)
```

`assets/` 不在 `.gitignore` 的 `data/` 里，会随仓库提交；部署脚本需要同步上传。

## 测试

`_test_cuotu.py`：

- 参数拆分、别名、未知表情
- 两个模板共 5 张底图都能渲染成 JPEG，尺寸正确
- 超长文字、未知模板被拒绝
- 指令接线：出图、缺文字、列表、未知表情、超长提示、敏感词
- `/help` 与主帮助包含搓图

## 备注

- 纯本地渲染，不调用模型、不联网、不产生 API 费用。
- 和人格链路共用 `sensitive.filter`：命中敏感词直接拒绝出图，不单独绕过。
- 目前有睦子米、大肥鱼说两个模板；以后加祥子/爱音只需在 `_TEMPLATES` 增加条目和素材。
