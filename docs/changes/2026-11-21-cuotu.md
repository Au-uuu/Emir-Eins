# 搓图：/搓图 <表情名> <要加的字>

- 日期：2026-11-21
- 模块：`cuotu.py`、`bot.py`、`assets/`
- 影响：新增群聊/单聊指令

## 需求

发两段文字就能出一张“角色说这句话”的表情包，例如：

```text
/搓图 睦子米 今天也不想上班
```

第一个空格前是表情名，后面全部算要加的字（文字里可以有空格）。

## 模板来源

使用现成的 **睦子米说** 模板，而不是自己画：

- 上游：<https://github.com/anyliew/meme_emoji>
- 模板：`emoji/mygo_wakaba_mutsumi_say`
- 关键词：`睦子米说` / `若叶睦说`
- 4 张底图，空白气泡位置沿用原模板坐标
- 仓库 MIT；素材为网络二创，仓库声明“如有侵权请联系删除”

字体使用 `NotoSansSC-Bold.ttf`（SIL Open Font License），
避免服务器没有中文字体时出方块。

## 实现

### `cuotu.py`

- 模板注册表：`_TEMPLATES["mutsumi"]`
- 别名：睦子米 / 若叶睦 / 睦头人 / 小黄瓜 / 睦 / mutsumi
- `split_args()` 只按第一个空白拆分，保留文字中的空格
- 文字画进气泡：
  - 从大到小试字号，自动换行
  - 居中绘制，黑色文字
  - 最多 24 字；再长直接拒绝，避免缩成蚂蚁
- 输出 JPEG（quality 90），四张底图约 27~72KB
- 随机选底图；测试可传 `number=1~4`

### `bot.py`

- 新指令：`/搓图`，必须带斜杠
- 子命令：
  - `/搓图` → 完整用法
  - `/搓图 列表` → 当前支持的表情
  - `/搓图 睦子米` → 缺文字提示
  - `/搓图 不存在 文字` → 列出可用表情
- 每个会话每人 3 秒冷却（`QQ_BOT_CUOTU_COOLDOWN`，`0` 关闭）
- 图片走现有 `_reply_image_bytes()`，被动回复，不占主动消息额度
- `/help 搓图` 和主帮助均已接线

### 素材

```text
assets/
├─ fonts/NotoSansSC-Bold.ttf
└─ memes/mygo_wakaba_mutsumi_say/
   ├─ 1.png  (512×512)
   ├─ 2.png  (384×384)
   ├─ 3.png  (500×500)
   └─ 4.png  (500×500)
```

`assets/` 不在 `.gitignore` 的 `data/` 里，会随仓库提交；部署脚本需要同步上传。

## 测试

`_test_cuotu.py`：

- 参数拆分、别名、未知表情
- 4 张底图都能渲染成 JPEG，尺寸正确
- 超长文字、未知模板被拒绝
- 指令接线：出图、缺文字、列表、未知表情、超长提示
- `/help` 与主帮助包含搓图

## 备注

- 纯本地渲染，不调用模型、不联网、不产生 API 费用。
- 和人格链路共用 `sensitive.filter`：命中敏感词直接拒绝出图，不单独绕过。
- 目前只有睦子米一个模板；以后加祥子/爱音只需在 `_TEMPLATES` 增加条目和素材。
