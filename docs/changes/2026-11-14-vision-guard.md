# 识图误判：确认未联网 + 收紧视觉描述提示词

- 日期：2026-11-14
- 模块：`persona.py`、`bot.py`

## 现象

00:27 单聊图片，bot 回复：

> 这画面……峡谷地形，还有那个圆形区域，是《英雄联盟》吧。ID 是 IG……

00:28 第二张图后：

> 【订正】本机刚才说错了，这不是峡谷地图，是 Q 版插画……

## 日志结论

- 00:27:43 收到图片；
- 00:27:48 视觉调用 `in=464 out=292`；
- 00:27:51 人格调用 `in=6568 out=39`；
- **没有任何 `[websearch]` / `[联网]` 记录**。

因为 `search_should` 有 `and not media`：**图片/视频消息根本不触发联网搜索**。  
这次误判发生在视觉描述阶段：`deepseek-v4.1-flash` 把画面描述成了“峡谷/圆形区域/英雄联盟/ID IG”，人格只是顺着描述说下去。

打标器和 KB 当时已经是关闭状态（`QQ_BOT_TAGGER=0`、`QQ_BOT_KB=0`），所以不是它们带偏；但它们也无法提供额外纠错。

## 改动

1. `DESCRIBE_PROMPT` 增加约束：
   - 不要根据地图形状、UI 布局、局部图标或零散字母推断游戏名、战队名、选手 ID；
   - 只有画面明确写出完整名称时才引用，拿不准就写「不确定」。
2. 图片描述现在会写一条日志：
   ```text
   [视觉] 描述 N 字：...
   ```
   下次再误判，能直接看到是描述阶段错，还是人格阶段放大。
3. 图片仍不触发联网搜索（没有可靠的“以图搜图”链路，用错误描述去搜只会放大错误）。
4. **新图片不再默认当成上一张图的订正**：
   - 新发图片/视频、没有引用、正文也没说「刚才/上一张/同一张」时，注入
     `MEDIA_NEW_TOPIC_NOTE`，要求按这条内容重新理解，不要沿用上一轮话题；
   - 只有用户明确引用或说「这张和刚才那张」时才视为连续/相关问题。
