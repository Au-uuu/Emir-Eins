# 2026-09-23 自检发现并修复的 2 个逻辑问题

## 1. 单聊里 `/来只 猫 私有` 会抽到公开图片

`ImageStore._random_sync` 指定关键词时，`private` 层的条件是 `k.owner_group = ?`，
参数是群标识。单聊时群标识为空串，于是 `owner_group = ''` 恰好命中了**公开层**，
导致「私有」当成了「公开」。

**修复**：单聊（无群标识）请求 `private` 层时直接返回 `None`。

## 2. `/图库 关键词` 会带出别群私有词名

`_to_record` 取一张图的全部关键词时没有按层过滤，图片若同时挂在
「公开词 A」与「别群私有词 B」上，当前群看 A 时会把 B 的名字一并显示出来。

**修复**：`_to_record` 增加 `group` 参数，只回 `owner_group IN ('', 当前群)` 的关键词；
`random_image` / `search_images` 传入当前群。

## 自检范围

- 逐条核对了所有涉及 `keywords` / `gallery_privacy` 的 SQL，确认层字段没有遗漏。
- 对 45 条指令 ×（群聊/单聊）共 90 种输入做冒烟，**0 异常**。
- 复核了指令分派顺序（`/删除图库` 先于 `/删除`、`/取消关联` 先于 `/关联` 等）。
