# 2026-09-22 图库分层模型：公开层 + 每群私有层

## 背景

上一版把「关键词」整体绑定到某一个群：一旦 `/私有 猫` 给群A，猫就在别处彻底消失，
群B 也无法再 `/添加 猫`。实际需求是**分层**：

> 在群A设置私有后，还可以在群B新增，相当于私有后是一个 `<关键词+openid>`；
> 在群A查询图库返回的是 `<关键词>` + `<关键词+openid>`。

## 新模型

图库身份 = **`(关键词, owner_group)`**：

| owner_group | 含义 | 可见范围 |
|---|---|---|
| `''`（空） | 公开层 | 所有群 + 单聊 |
| 群 openid | 该群私有层 | 仅该群 |

- `/私有 猫`（群A）：把猫的**公开层图片全部移入 `(猫, A)`**，并打上私有标记；
  之后群A 的 `/添加 猫` 进 `(猫, A)`。
- 群B 仍可 `/添加 猫` → 进公开层；群A 的 `/图库` 同时显示 `猫` 和 `猫[私有]`。
- `/来只 猫`（群A）：公开层 + `(猫, A)` 一起抽；群B 只抽公开层。
- `/删除 猫`：**私有层优先**，私有层没有再看公开层。
- `/公开 猫`（群A）：把 `(猫, A)` **并回公开层**，去掉私有标记。
- 一个关键词可以同时在多个群里私有，各自独立。
- 别名仍全局解析到主关键词，私有层挂在主关键词上。

## 变更点

### 数据模型

- `keywords` 增列 `owner_group`，主键改为 `(image_id, keyword, owner_group)`。
- `gallery_privacy` 主键改为 `(keyword, group_openid)`（多对多）。
- **迁移**：`ImageStore._migrate` 一次性把旧库升级：
  - 旧 `keywords` 的图片补 `owner_group=''`；
  - `gallery_privacy` 重建为复合主键；
  - 关键一步：旧库里被标记为私有的关键词，其图片原本都在公开层，
    迁移时按标记**搬到对应群私有层**，保持「私有内容只在该群可见」。

### 读路径

所有查询都按 `owner_group IN ('', 当前群)` 过滤：

- `random_image` / `search_images` / `image_ids_for_keyword`：关键词检索限定层；
- `list_galleries`：按 `(keyword, owner_group)` 分组，返回四元组
  `(关键词, 数量, 关联词, owner_group)`，同名公开层/私有层各占一条；
- `gallery_count`：按 `(keyword, owner_group)` 计数；
- `stats` / `list_keywords` / 图片可见性：按层过滤。

### 写路径

- `add_from_attachment`：解析主关键词后，本群设过私有 → 落 `(词, 本群)`，否则公开层。
- `set_gallery_private`：公开层 → 本群私有层 + 标记。
- `set_gallery_public`：本群私有层 → 公开层 + 去标记。
- `delete_from_gallery`：私有层优先，再公开层；孤儿文件照旧清理。

### 指令

- `/私有`、`/公开` 语义更新（见上）；群聊与「管理员私聊按群 openid」两条路径一致。
- `/图库` 列表里本群私有层带 `[私有]`；同名公开层与私有层分别显示。

## 改动文件

- `image_store.py`：schema、迁移 `_migrate`/`_ensure_indexes`、可见性辅助改为按层、
  全部读写路径、私有 CRUD（`is_gallery_private` 替代 `gallery_private_group`；
  `gallery_privacy_map` 改为返回 `[(词, 群), ...]`）。
- `bot.py`：`build_gallery_list_text` 用四元组的 owner 打标；`/图库 关键词` 用
  `is_gallery_private`；`/公开` 传群；`/私有` 文案说明「移入私有层」。
- `_test_privacy.py`：按分层模型重写。
- `_test_gallery.py`：适配四元组（` / ` 分隔等断言不变，因组名/数量索引未变）。
- `README.md`：群私有说明改为分层模型。

## 测试

9 项测试全绿；并在**服务器真实库副本**上验证迁移：63 行关键词保留、
6 个私有标记按层搬迁、`蒙鑫` 仅在该群可见。

## 备注

- 同名公开层与私有层在 `/图库` 里会各占一条（都标同一组关联词），这是预期。
- `/私有` 会把公开层清空并入私有层，因此**其它群会立刻看不到这批图**——这正是分层语义。
- 群 openid 用机器人视角的标识，与 QQ 群号无关。
