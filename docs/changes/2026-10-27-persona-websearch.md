# 爱因味回补 + 联网搜索准确性

- 日期：2026-10-27
- 涉及：`persona/依蜜尔爱因.md`、`bot.py`、`websearch.py`、
  `_test_websearch.py`、`.env.example`、`README.md`

## 1. 爱因味回补

- 「群聊每 2~3 条至少一处机娘味」改成 **每 1~2 条至少一处**；
- 增加「风味自检」：完全没有本机/机械词/标签/毒舌/汉字报时就补一个；
- 群聊标签从「最多一个、可以完全不用」改成「通常一个，情绪强可两个」；
- 示例补回标签：`【肯定】强是强…`、`【考察】新角色和两个活动…`；
- 新增**场景提示**：群聊时告诉模型「对方是未知个体，不是主人；禁止叫主人」，
  单聊才说「对方是主人」。之前群聊里偶尔冒出「主人」的问题解决。
- 仍然禁止报告体连发（`【报告】…【建议】…【结论】…`）。

## 2. 联网搜索为什么之前不准

实测：`qwen-flash` + `enable_search=True` 时，模型**可以自己决定不搜**，
于是拿训练数据硬答。问「终末地新角色」，返回了「截至 2024 年 6 月…」的旧答案。

修正：

```json
{
  "enable_search": true,
  "search_options": {
    "forced_search": true,
    "search_strategy": "turbo"
  }
}
```

- `forced_search=true`：强制真搜，不让模型偷懒；
- system prompt 加当前日期，并要求「搜不到就说未查到，不要用旧知识硬答」；
- `QQ_BOT_WEBSEARCH_FRESHNESS=7/30/180/365` 可选，只搜最近 N 天；
- 触发词扩到：新角色/新干员/新皮肤/卡池/复刻/值得抽/强度/配队/攻略/剧情/结局/
  是谁/叫什么/哪一位/多少抽；
- 带图/视频的「这是谁」不搜（图和打标/KB 更直接）；
- 自我介绍（你是谁/本机是谁/你叫什么）不搜；
- 搜索失败仍然静默。

实测（2026-10-27）：

| 查询 | 结果 |
|---|---|
| 上海今天天气 | 2026-10-27 阴转晴 14~21℃，偏北风 4~5 级（当前） |
| 2026-10-27 AI 最新新闻 | 4 条当日新闻（当前） |
| 明日方舟 终末地 2026-10 新角色 | 丹青渡版本、祀/明河两名干员（当前） |

## 3. DS 与搜索的关系

- 聊天/识图：DS V4.1 Flash（OpenCode Go）
- 联网检索：Qwen `enable_search`（DashScope）
- **DS 没有内置联网搜索**，所以检索仍是独立两步：Qwen 取事实摘要 → DS 按人设回答。
- 不建议每条都搜：只对时效/事实类问题触发；闲聊、看图、自我介绍不搜。

## 3. 测试

- `_test_websearch.py` 新增：新角色/卡池触发、自我介绍不触发、

## 4. 新梗：疯狂新妻祀

群友反馈「看不懂疯狂新妻祀」，原因是 KB 只有「祀」的设定，没有 2026-10 的新梗。

修法：

- 新增服务器 KB 文件 `data/kb/新梗.md`（本地同路径也留一份）：
  - `## 疯狂新妻祀`：终末地「丹青渡」新角色祀的社区梗；
  - `## 疯狂星期祀`：谐音肯德基疯狂星期四；
  - `## 新妻祀` / `## 小葱（祀）`：梗称与玩家昵称；
- 联网触发词增加：`什么梗|什么鬼|什么意思|看不懂|没听过|不认识|新梗|热梗|出处|出典`；
- 角色卡增加：「遇到不认识的梗/新词先用资料或搜索；搜不到就问一句，不许装懂、不许编来源」。
- 验证：
  - `kb.context("疯狂新妻祀")` 能召回条目；
  - `kb.context("小葱是谁")` 能召回；
  - 搜索“疯狂新妻祀 是什么梗”能返回 2026-10 社区梗解释（但搜索解释不如 KB 准，所以 KB 为主、搜索兜底）。
- 之后遇到新梗：优先 `/黑话 添加 词 解释`，或把条目写进 `data/kb/新梗.md`；自动学习只会在有上下文依据时提取，不会凭空知道一个新梗。
