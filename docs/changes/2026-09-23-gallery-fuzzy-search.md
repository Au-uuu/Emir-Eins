# 2026-09-23 `/图库 <关键词>` 模糊搜索

## 需求

`/图库 <关键词>` 精确查不到时，做模糊搜索，给出**相关关键词**。

## 实现

- 新增 `ImageStore.find_keywords(query, group, limit)`：
  - 取当前群可见关键词（`owner_group IN ('', 群)`）及其数量；
  - 关键词或**别名**满足「query 是它的子串」或「它包含 query」即命中；
  - 排序：子串越靠前越优先（前缀最好），同分按数量降序；
  - 精确等于 query 的不返回（精确的走正常流程）。
- `do_gallery` 关键词分支：精确查无图时调用 `find_keywords`，
  有结果就回「没有「kw」这个图库，你是不是想找：」(每行 `词（数量）`)，
  没有才回原来的「没有图片」。

## 例子

- `/图库 猫猫` → 无精确命中，因「猫」是「猫猫」的子串 → 推荐 `猫(3)`。
- `/图库 ki` → 别名 `kitty` 命中 → 推荐 `猫(3)`。
