# 2026-09-22 openid 查询 + 管理员私聊按群设私有

## 需求

- 新增查询：能查到**当前群 openid** 和**自己的用户 openid**。
- 管理员账户可在**私聊**里 `/私有 <图库名> <群聊id>`，把图库绑定到指定群。
- 其他情况：`/私有`、`/公开` **只在群聊里**触发。

## 设计

### `/id`（辅助指令，未列入帮助）

- 正则 `^/(?:id|whoami|我的id)\b`（必须带斜杠）。
- 群聊回复：自己的 openid + 当前群 openid。
- 单聊回复：自己的 openid（并提示单聊没有群 openid）。

### `/私有`

| 场景 | 行为 |
|---|---|
| 群聊 `/私有 图库名` | 绑定到当前群（不变） |
| 私聊 `/私有 图库名 <群openid>` | **仅管理员**；管理员判定用 openid 查 `admins` 表 |
| 私聊 `/私有 图库名`（缺群 id） | 提示用法 |
| 私聊非管理员 | 提示「只有管理员…」 |

### `/公开`

- 仅群聊触发；私聊里一律回复「`/公开` 只能在群聊里使用」。

## 改动文件

- `README.md`：指令表与群私有说明同步。

## 测试

9 项测试全绿。

## 备注

- 私聊设私有使用的 `<群openid>` 不做格式校验，任意非空串都接受；
  填错会绑定到一个不存在的群（群里看不到，也取不到），可再用 `/私有` 改正。
- `/id` 会显示调用者自己的 openid 与所在群 openid，均为机器人视角下的不透明标识，
  与 QQ 号无关。
