# 2026-09-22 入库提示：大小在前、格式放括号

## 需求

入库成功提示的这一行，从
```
JPEG  大小：107.7 KB
```
改成
```
大小：107.7 KB（JPEG）
```

## 改动

- `bot.py` `do_add_image`：`f"{fmt_label}  大小：{size_kb:.1f} KB"` →
  `f"大小：{size_kb:.1f} KB（{fmt_label}）"`。
- `_test_add.py`：断言改为「行以 `大小：` 开头且含 `（PNG）`」。

## 效果

```
入库成功 #12
关键词：猫
大小：107.7 KB（JPEG）
指纹：a1b2c3d4e5f6…
```

格式标签仍优先取转换说明（如 `已由 WEBP 转为 PNG`），GIF 显示 `GIF 动图`。
