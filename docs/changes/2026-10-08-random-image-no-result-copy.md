# 「来只」查不到图时的提示：去掉「层」的说法，并给出相近关键词

日期：2026-10-08

## 需求

线上出现这种回复（用户截图）：

```
用户：来只金鑫
机器人：没有找到关键词「金鑫」在「全部」层里的图片，换个词/层或先用 /添加 存图。
```

两个毛病：

1. **把内部概念当成了用户操作**。「全部」层是分层模型（公开层 / 每群私有层）的内部
   说法；用户根本没指定层、也不关心层。更离谱的是「换个层」——那是实现细节，不是
   用户能做的事。
2. **只说「换个词」却不给候选**。同一个机器人的 `/图库 关键词` 是有模糊推荐的
   （「你是不是想找：猫（12）」），`/来只` 这里却不一致。

## 设计

新增 `_reply_no_random_image()`，替掉原来内联的三行文案：

| 情况 | 新文案 |
|---|---|
| 没指定层、关键词查不到 | `没有「金鑫」的图。引用一张图回复「/添加 金鑫」就能存进来。` |
| 查不到、但库里有相近词 | `没有「deep」的图，你是不是想找：` + `deepseek（2）` |
| 指定了层 | `本群私有图库里没有「金鑫」的图。…` / `公开图库里没有…`（**仍不出现「层」字**） |
| 没给关键词（空图库） | `还没有图片，先用 /添加 存几张吧。` |
| 是别名 | 追加 `（已按关联词「X」查）` |

几条实现细节：

- 层 → 自然说法靠 `_LAYER_PHRASE` 映射，`all` 映射成空串（**压根不提层**）
- 相近词推荐复用 `store.find_keywords()`，并**排除关键词本身与它的主词**——否则会
  出现「没有『猫』的图，你是不是想找：猫（12）」这种鬼话
- 原「（已按主关键词「X」查询）」简化为「（已按关联词「X」查）」
