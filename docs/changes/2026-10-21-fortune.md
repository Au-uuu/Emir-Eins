# 2026-10-21 /今日运势：本地黄历 + 确定性抽签

## 需求

群里想要每日运势功能；要求同人同日结果固定（重发不能「刷好运」）、不依赖外部
API、语气走人格的【报告】体。

## 设计

- 新增 `fortune.py`：
  - 黄历用 `lunar-python` 本地算（农历/干支/宜忌/冲煞/值神），不联网、不需 key；
    未安装或计算失败只丢黄历块，不影响运势本体。
  - 运势按 `sha256(日期:openid)` 抽签：四维（财运/姻缘/事业/人品）各 0~2，和为
    8 级（0~8），中间档概率高（看着比均匀随机自然）；同一天同一人结果固定。
  - 每级 2 条七言签文 + 一句点评；结尾带「仅供娱乐」。
- `bot.py`：`/今日运势` 与 `/运势`（必须带斜杠），帮助里加一行。
- 依赖：`requirements.txt` 加 `lunar-python`（纯 Python）。

## 改动文件

- `fortune.py`（新增）、`bot.py`、`requirements.txt`、`_test_fortune.py`（新增）

## 测试

- 自动化：`_test_fortune` 15 项（确定性/换日变化/四维与等级一致/300 人覆盖 0~8
  全档/不同人不同/排版关键字/黄历块）全过。
- 人工（待办）：群里真机发 `/今日运势` 看排版；同一人重发结果一致；不同人结果不同。

## 备注

- 部署时需在服务器 `pip install lunar-python`（已装 1.4.8）。
